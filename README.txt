BAKERU 商品・在庫管理 v2.7.1
QR商品・在庫管理＋現場運用ブラッシュアップ版

【今回の追加機能】
1. バーコードのない商品にBAKERU専用QRを自動作成
2. 商品登録時に以下を追加
   - 内容量
   - 内容量単位（g / kg / ml / L / 個 / 本 / 袋 / 箱など）
   - 商品特徴・規格メモ
   - 棚・保管場所
3. 商品一覧に「QR作成」ボタン追加
4. 同じ商品から用途別に印刷可能
   - 商品ラベル：商品現物・仕入れ品へ貼付
   - 棚ラベル：棚・保管場所へ貼付
   - 入出庫カード：A6程度で印刷しラミネートして繰り返し使用
5. スキャン画面でJAN/1次元コード + BAKERU専用QRを読み取り
6. QR読取後に最新の商品名・内容量・特徴・棚位置・現在庫を表示
7. 読取画面からそのまま「入庫」「出庫」→数量・単位→確定
8. BAKERU専用QRは同じ日に何度でも入出庫用として使用可能
9. 棚卸・領収書検品でもBAKERU専用QRから商品を特定可能
10. QRには商品詳細を固定保存せず商品IDだけを保存
    → 内容量・価格・特徴・棚位置を後から変更してもQR再発行不要

【重要：今回変更するファイル】
GitHub Pages側：index.html
Google Apps Script側：Code.gs

今回は商品マスターに新しい保存項目を追加するため、
index.htmlだけではなくCode.gsも更新してください。

【安全な更新手順】
STEP 1
現在のBAKERUフォルダーを念のためコピーしてバックアップします。

STEP 2
GitHubのBAKERUリポジトリで index.html を、このZIP内の index.html に上書きします。

STEP 3
BAKERUのGoogleスプレッドシート → 拡張機能 → Apps Script を開きます。
既存の Code.gs を、このZIP内の Code.gs の内容で全置換して保存します。

STEP 4
Apps Script上で setupBAKERU() を1回実行します。
既存の01_商品マスタのデータは残したまま、末尾に追加列を作成します。
追加列：
仕入単位 / 換算量 / 注意在庫 / 通知Gmail / 内容量 / 内容量単位 / 商品特徴 / 棚・保管場所

既にT01_商品マスタ等のテストシートが存在する場合も、追加列を安全に拡張します。

STEP 5
Apps Scriptの「デプロイ」→「デプロイを管理」から既存Webアプリを編集し、
新しいバージョンとしてデプロイします。
既存のWebアプリURLはそのまま維持してください。

STEP 6
GitHub PagesのBAKERUを開き、左上が v2.7.1 になっていることを確認します。

【QRの使い方】
A. 商品現物に貼る
商品・在庫 → 商品登録 → 詳細入力 → 保存 → QR作成 → 商品ラベル
印刷して仕入れ商品に貼ります。

B. 棚に貼る
QR作成 → 棚ラベル
棚や保管ケースに貼っておきます。
スマホで読み取ると、その商品の最新情報と現在庫を確認できます。

C. ラミネートして入庫・出庫に使う
QR作成 → 入出庫カード
A6程度で印刷してラミネートします。
作業時：
  1. スキャン・検品を開く
  2. QRを読む
  3. 入庫 または 出庫を選ぶ
  4. 数量と単位を入力
  5. 確定
同じカードを何度でも使用できます。

【QRに入っている情報】
例：BAKERU:P:prod_xxxxx
QRには商品IDだけを入れています。
商品名・内容量・特徴・価格・現在庫などはGoogle Sheetsの商品マスターから最新値を呼び出します。

【既存JANバーコード商品】
今までどおりJAN/EAN/Code128等をそのまま利用できます。
バーコードがある商品までBAKERU専用QRへ変更する必要はありません。

推奨運用：
既製品 → メーカーJANバーコード
バーコードなし商品 → BAKERU専用QR
棚・入出庫カード → BAKERU専用QR



【v2.7.1 現場運用ブラッシュアップ】
1. 在庫アラートを本当の2段階に強化
   - 🟡 注意在庫：発注準備
   - 🔴 レッド在庫：早急な発注・補充
   在庫が回復すると該当アラートは自動で解決済みに切り替わります。
2. 出庫を「販売」「使用」に分離
   - 販売：お客様への販売
   - 使用：店内・製造・試飲など業務使用
   Google Sheetsの02_入出庫履歴にも種別を分けて記録します。
3. QR読取後の現場操作を3ボタン化
   入庫 / 販売 / 使用
4. 数量のクイックボタン 1・2・5・10 を追加
5. 販売・使用前に「処理後在庫」を表示
   注意ライン・レッドラインへ入る場合は色で確認できます。
6. 二重タップ防止
   記録中は確定ボタンを無効化し、同じ処理を連打しにくくしました。
7. ダッシュボードに
   🟡 注意在庫の商品数 / 🔴 レッド在庫の商品数 を常時表示します。

【重要】
今回はindex.htmlとCode.gsの両方を更新してください。
GASは既存Webアプリを「新しいバージョン」で再デプロイします。URLは変更しません。

8. 販売時は販売単価、入庫・使用時は仕入単価を入出庫履歴の金額計算に使用するよう修正。
9. 商品ごとの「通知Gmail」が設定されている場合、注意ライン到達時とレッドライン到達時に各1回メール通知します。
   同じ段階で何度も連続送信しない設計です。在庫回復後に再び下がった場合は再通知します。

10. QR印刷ラベルのQR下に「管理番号：SKU（または商品ID）」を表示。
    商品貼付用は58×40mmラベル内でQR約24mm角の小さめ設計にし、情報を詰め込み過ぎない表示へ調整しました。
