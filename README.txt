BAKERU v2.6.7 STEP3 — 本番／テスト切替 UI

今回の変更は index.html のみです。
前提：GAS は v2.6.6 STEP2（テストデータ完全分離版）をデプロイ済みであること。

使い方
1. GitHub の index.html をこの版で上書き
2. BAKERUを開く
3. 画面右上の「本番 / テスト」で「テスト」を押す
4. オレンジ色の「テストモード中」表示が出ればOK
5. テスト中の商品登録は T01_商品マスタ、入出庫は T02_入出庫履歴に保存
6. 「本番」を押すと本番データに戻る

安全設計
- ページを開き直すと必ず本番モードから開始します。
- テストモードでは、STEP3未対応の本番書込系操作（商品削除・領収書確定・棚卸保存等）をブロックします。
- テスト商品が0件でも、バーコードを読み取り未登録商品として登録できます。

GASの再変更は不要です。
